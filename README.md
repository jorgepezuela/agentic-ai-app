# Agentic AI Applications

Welcome to the Agentic AI Applications repository! This collection showcases various examples of AI agents designed for different purposes. Each project is self-contained within its respective directory.

## Projects

Below is a list of the AI agent examples included in this repository:

### 1. Basic Agents

This directory contains fundamental examples of agentic AI:

*   **`simpleagent.py`**: A straightforward implementation of a basic AI agent.
*   **`agent_memory.py`**: Demonstrates an AI agent with memory capabilities, allowing it to retain and recall information.
*   **`multiagents.py`**: An example showcasing a system with multiple AI agents, potentially interacting with each other or working in parallel.

### 2. Financial AI Analyst

This project focuses on an AI agent designed for financial analysis tasks:

*   **`financial_agent.py`**: The core script for the financial AI analyst agent.
*   **`playground.py`**: A utility script, likely for experimenting with or testing the `financial_agent.py`.
*   **`requirements.txt`**: Lists the Python dependencies required to run the Financial AI Analyst.

### 3. Video Summarizer

This project provides an AI agent capable of summarizing video content:

*   **`app.py`**: The main application file for the Video Summarizer agent.
*   **`requirements.txt`**: Lists the Python dependencies required to run the Video Summarizer.

## Getting Started

To run any of these examples, navigate to the specific project directory. If a `requirements.txt` file is present, you should install the necessary dependencies, typically using a command like:

```bash
pip install -r requirements.txt
```

Then, you can execute the main Python script for that agent (e.g., `python app.py` or `python financial_agent.py`).
